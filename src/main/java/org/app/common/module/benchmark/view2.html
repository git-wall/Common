🚀 Cách sử dụng:

  1. Click "Load Folder" → Chọn thư mục profiles/
  2. Chọn API từ sidebar bên trái
  3. Chọn versions cần so sánh (tối đa 3, version đầu là baseline)
  4. Click "So sánh" để xem kết quả
  5. Chuyển tabs để xem Average/Min/Max/Tổng Kết

💡 Giải thích kết quả:

  • ↓ Màu xanh + ✓ = Giảm so với baseline (TỐT - performance cải thiện)
  • ↑ Màu đỏ + ✗ = Tăng so với baseline (XẤU - performance giảm)
  • = Màu vàng = Không đổi
  • Range = Max - Min (khoảng dao động, số càng nhỏ = ổn định)
